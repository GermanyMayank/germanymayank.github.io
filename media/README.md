# Tour media

The source clip is the selected 24–28 second segment of the LONGi Qatar solar-plant video. It is not yet present because its Library transfer failed in the build workspace.

Run `npm run media -- --input /absolute/path/clip.mp4`, then `npm run build` from the repository root. This creates the seek-optimised MP4 and poster here and updates the tour configuration. See the root README for full instructions.
